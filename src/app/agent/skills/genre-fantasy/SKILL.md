# 西方奇幻题材规范

## 何时使用
`novel.yaml` 的 `genre` 为奇幻 / 西幻 / 剑与魔法 / 异世界时，与 `prose-writing` 配合使用。

## 魔法体系（桑德森定律）
- **硬魔法**：规则明确、代价清晰、可预测——适合让主角用智谋解决问题（如《迷雾之子》）。
- **软魔法**：神秘、不可测、营造氛围——适合制造敬畏与悬念（如《魔戒》）。
- **核心原则**：魔法的**限制**比能力更重要。能用魔法解决什么问题，取决于它不能解决什么。
- 体系一旦确立，全书必须自洽，不能为方便剧情临时加规则。
- 代价机制：消耗（体力 / 生命 / 理智）、材料、时间、反噬——无代价的魔法等于无张力。

## 世界观构建
- 地理决定文明：气候、资源、地形塑造种族分布、经济与冲突。
- 历史要有纵深：当前局势是历史的结果（旧战争、衰落帝国、古老预言）。
- 多势力博弈：王国、教会、法师塔、佣兵团、异族——各有利益，不要铁板一块。
- 设定服务于故事：**只展示与剧情相关的设定**，其余藏在冰山之下，不要倾泻。

## 种族与文化
- 避免脸谱化：不是所有精灵都高傲、所有矮人都贪杯、所有兽人都野蛮。
- 每个种族 / 文化要有内在逻辑（信仰、习俗、经济、与其他种族的关系）。
- 文化借鉴要谨慎，避免对现实民族的刻板印象。

## 命名风格（配合 naming 技能）
| 元素 | 风格 | 示例 |
| --- | --- | --- |
| 人名 | 音节自洽，同一文化内风格统一 | 艾兰迪尔、凯恩、瑟琳娜 |
| 地名 | 含语言感，可标注含义 | 银月城（Elun'dore）、黑岩隘口 |
| 种族 / 语言 | 自创音节体系保持一致 | 精灵语多流音，兽人语多塞音 |

**关键**：命名要有「语言一致性」——同一文化的名字共享音节规律，读者能凭直觉分辨归属。用 `grep` 核对全书命名统一。

## 史诗感营造
- 个人命运与宏大背景交织：小人物卷入大势，或大人物面对私人抉择。
- 旅程结构：出发 → 试炼 → 盟友与背叛 → 至暗时刻 → 决战 → 归返（可打破但要有理由）。
- 预言与宿命：可用作伏笔，但要避免「一切早已注定」削弱人物能动性。
- 牺牲要有重量：死亡的角色要对读者有情感积累，不要为煽情而死。

## 战斗与冒险
- 魔法战斗要有战术：利用规则、环境、团队配合，而非「谁的火球更大」。
- 冒险旅程写出艰辛：补给、伤病、天气、迷路——真实感来自代价。
- 怪物 / 敌人要有生态与动机，不是无脑刷怪。

## 常见雷区（务必规避）
- 「天选之子」过度：主角因血统 / 预言无敌，缺乏成长与挣扎
- 设定倾泻：开篇大段世界观说明，无人物无冲突
- 魔法万能：靠魔法解决一切，丧失张力
- 命名混乱：同一文化名字风格不一，读者记不住
- 西方中心套路：照搬中世纪欧洲而无反思，或混杂多种文化元素却无逻辑
- 现代价值观硬植入：人物用现代思维说教，破坏沉浸

## 文风基调
- 叙述可带古典韵味，但不必全文言（平衡可读性与氛围）。
- 意象系统统一（光与暗、元素、星辰、古树），贯穿全书形成风格标识。
- 描写调动异域感官： unfamiliar 的气味、光线、声音，营造「另一个世界」的疏离与惊奇。
