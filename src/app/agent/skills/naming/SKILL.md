# 命名创作

## 何时使用
- 新建人物 / 地点 / 势力 / 功法 / 道具需要命名
- 现有名字与题材气质不符，需要改名
- 大纲卷名章名过于笼统（「第一卷」「第三章」），需要具体化
- 发现重名或谐音歧义需要替换

## 命名铁律（项目硬约束）
- **卷名章名必须具体**：禁止「未命名」「第一卷」「第 1 章」这类默认名或纯序号名——API 会以 `42201` 拒绝。
  - 反例：`# 第一卷` / `## 第三章`
  - 正例：`# 第一卷 荒原初醒` / `## 第三章 拾荒少年的清晨`
- 序号前缀**可以保留**（`第X卷` / `第X章`），但后面必须跟具体名称。
- 改名时**不要改文件名**：章节文件路径含 ID，改名会让修订快照、摘要、阅读进度失效。只改 `title` 字段或大纲小节标题。

## 人物命名
| 题材 | 风格 | 示例 |
| --- | --- | --- |
| 玄幻 / 仙侠 | 古风双字或三字，含意象 | 苏长渊、叶知秋、顾寒山 |
| 都市 / 现实 | 现代常见姓 + 有辨识度名 | 陈默、林晚、周斯越 |
| 奇幻 / 西幻 | 音译感或自创音节 | 艾瑞克·维斯、莉安娜 |
| 科幻 | 简洁，可带编号或代号 | 秦昭、K-7、沈星回 |

**技巧**：
- 姓氏避开口音相同的角色（张三 / 章珊）
- 主要人物名之间不要同音同调（李伟 / 李薇）
- 配角名可比主角名「轻」，避免喧宾夺主
- 反派名不必带恶字，反差更有张力
- 用 `grep` 检索全文确认不重名

## 地名 / 势力命名
- 地名：地形 + 意象（落雁峰、雾隐城、断刃荒原）
- 势力：功能或理念 + 组织后缀（听雨楼、镇魔司、第七研究院）
- 避免过度堆砌生僻字——读者记不住的名字等于没有名字

## 功法 / 技能 / 道具命名
- 功法：意象 + 动作或境界（焚天诀、听风步、九重寒霜）
- 分级命名保持体系一致（凡阶 / 灵阶 / 天阶，不要混用「级 / 品 / 阶」）
- 道具名要有来历感，不要「强大的剑」这类直白命名

## 卷名章名
- **卷名**：概括该卷核心冲突或转折（4–8 字），如「荒原初醒」「风暴之眼」「长夜将尽」
- **章名**：提示本章核心事件或情绪（6–14 字），如「拾荒少年的清晨」「第一次杀意」
- 避免剧透式章名（「主角获得神器」），改用悬念式（「锈铁下的微光」）
- 同一卷内章名风格保持一致（都用意象 / 都用动作）

## 交付格式
给出候选时提供 **3–5 个选项**，每个附一句理由，便于用户挑选：

```
### 人物命名候选（题材：玄幻）
1. 苏长渊 —— 「渊」暗示深藏不露，与其隐忍性格契合
2. 顾寒山 —— 冷硬意象，适合亦正亦邪的定位
3. 叶知秋 —— 中性偏文，若角色是谋士型更合适
```

## 改名操作流程
1. 先 `grep` 旧名，确认全部出现位置（正文 / 大纲 / 附录）。
2. 用 `edit_file` 逐处替换（或 `replace_all`），**不要遗漏大纲附录 B 的人物登记**。
3. 章节 `title` 改名走项目管理 API（`PATCH /chapters/{id}`），不要在正文 frontmatter 里直接改——那样 DB 登记会不同步。
4. 改完 `grep` 旧名确认已无残留。
