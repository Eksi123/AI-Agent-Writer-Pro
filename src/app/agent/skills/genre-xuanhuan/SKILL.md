# 玄幻仙侠题材规范

## 何时使用
`novel.yaml` 的 `genre` 为玄幻 / 仙侠 / 修真 / 东方奇幻时，与 `prose-writing` 配合使用。

## 境界体系（附录 C 必须明确）
- **层级数量**：建议 6–9 个大境界，每个大境界 3–9 小层。过多读者记不住，过少缺乏成长感。
- **命名一致**：全书统一一套命名（炼气→筑基→金丹→元婴，或淬体→通脉→凝罡→化神），**不要中途换体系**。
- **压制规则**：跨大境界碾压是爽点基础，必须先立规则再破规则（主角越级而战需要明确代价或特殊依凭）。
- **突破门槛**：每次突破要有契机（机缘 / 顿悟 / 生死历练），避免「修炼几日便突破」。

## 金手指设计
| 类型 | 优点 | 风险 |
| --- | --- | --- |
| 系统面板 | 成长可视化，读者易代入 | 过于游戏化，削弱世界观沉浸 |
| 老爷爷 / 传承 | 有来历感，可埋伏笔 | 沦为万能解答，主角失去主动性 |
| 特殊体质 / 血脉 | 与世界观绑定自然 | 需解释为何独此一人 |
| 重生 / 先知 | 天然爽点与信息差 | 先知优势用尽后节奏崩塌 |

**核心约束**：金手指必须有**明确限制与代价**（冷却、消耗、副作用、条件），否则冲突失效。

## 爽点节奏
- 每 3–5 章一个明确爽点（打脸、突破、夺宝、身份揭晓）。
- 压抑不超过 3 章——读者耐心有限，长期憋屈会弃书。
- 打脸三段式：轻视 → 反转 → 余波（旁观者反应、后续影响）。
- 越级战胜后要有实质收益（资源、名声、势力变化），不要「白打一场」。

## 宗门 / 势力结构
- 层级：外门 → 内门 → 真传 → 长老 → 掌门（或等价体系），全书统一。
- 势力间要有利益冲突，不要铁板一块的「正派」。
- 主角在势力内的地位变化要写清楚（资源分配、话语权、敌对派系）。

## 常见雷区（务必规避）
- 境界体系前后矛盾（前期说金丹无敌，后期金丹满地走）
- 配角工具化：只在主角需要时出现，无自身动机
- 女性角色扁平化：只有「红颜知己」功能而无独立目标
- 无限套娃：打了小的来老的，打了老的来更老的，无终局感
- 修炼描写流水账：「他打坐三个时辰，吸收灵气」重复出现
- 世界观倾泻：开篇三章全是设定说明，无人物无冲突

## 战斗场景写法
1. **起势**：交代双方境界差、环境、赌注（为什么必须打）。
2. **交手**：招式有名有实（不要「无数道攻击」），有攻防转换，有意外。
3. **转折**：底牌 / 金手指 / 环境利用 / 心理博弈，要有前置铺垫。
4. **收尾**：明确结果与代价（伤势、消耗、后续影响）。
5. 避免：招式堆砌无逻辑、旁白解说过多、旁观者惊呼刷屏。

## 文风基调
- 叙述可略带古意，但对话不宜全文言（阅读门槛）。
- 意象系统统一（剑气 / 道韵 / 天机），不要混用科幻术语。
- 章节结尾留钩子：危机将至、机缘显现、身份存疑。
