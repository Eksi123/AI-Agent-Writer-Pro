# 都市现实题材规范

## 何时使用
`novel.yaml` 的 `genre` 为都市 / 现实 / 职场 / 悬疑 / 都市言情时，与 `prose-writing` 配合使用。

## 真实感是第一生命线
都市题材读者就生活在其中，**任何失真都会出戏**：
- 城市细节：地铁线路、通勤时间、房租水平、外卖、天气、方言——用 `web_search` 查证不确定的真实信息。
- 职业细节：行业术语、工作流程、职级称谓、薪资范围必须可信。写医生就要懂值班与病历，写律师就要懂庭审程序。
- 时代细节：手机型号、社交软件、流行语要与故事年代匹配，避免穿越式错位。
- 金钱细节：具体金额要符合现实（一线城市房租、工资、物价），不要随手写「几百万」。

## 冲突来源（都市题材的张力引擎）
| 来源 | 示例 |
| --- | --- |
| 职场 | 晋升竞争、背锅、裁员、办公室政治、创业成败 |
| 家庭 | 代际观念冲突、婚恋压力、原生家庭、赡养与抚养 |
| 阶层 | 资源不对等、身份落差、上升通道堵塞 |
| 情感 | 信任与背叛、错过与遗憾、现实与理想的拉扯 |
| 社会 | 突发事件、舆论、制度与个人的摩擦 |

都市题材的冲突往往**内向而绵密**，不靠打斗靠处境，不靠反派靠两难。

## 人物塑造
- 配角要有自己的生活逻辑，不是主角的陪衬或工具。
- 反派（若有）动机要可信——都市里更多是「立场不同的人」而非「纯粹的恶」。
- 主角的成长靠认知与选择的转变，而非外挂能力提升。
- 对白要有身份感：不同职业、年龄、地域的人说话方式不同。

## 悬疑 / 推理子类补充
- 线索公平：关键线索必须提前给读者，不能结尾凭空冒出。
- 诡计可验证：手法要符合物理与现实逻辑。
- 节奏：悬念层层递进，每章结尾留钩子，但不要用假悬念骗读者。
- 用 `continuity-check` 技能核查时间线与线索一致性。

## 常见雷区（务必规避）
- 「霸道总裁」式悬浮：脱离现实的身份与财富设定，缺乏可信细节
- 主角光环过重：所有人都围着主角转，配角无人格
- 说教与价值观灌输：把观点直接塞进对白
- 细节失真：职业、城市、时代任何一处露怯
- 冲突靠误会：本可一句话解决的误会拖几十章
- 情节注水：大量无关日常凑字数

## 文风基调
- 语言贴近生活，可带地域特色与时代气息，但不堆砌网络流行语（易过时）。
- 场景描写调动都市感官：噪音、灯光、气味、拥挤、节奏。
- 情绪克制——都市题材的力量常在留白与细节，而非直白抒情。
