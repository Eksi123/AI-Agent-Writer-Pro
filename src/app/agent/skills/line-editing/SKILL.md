# 文字润色与去水

## 何时使用
- 章节初稿完成后打磨
- 正文读起来拖沓、啰嗦、节奏松散
- 人物称谓、语气、术语前后不统一

## 硬性边界
- **只做文字层面修改**：不改剧情、不改人物决定、不加新情节、不删关键情节点。
- 用 `edit_file` **精准替换**目标句段，不要用 `write_file` 重写整章（除非用户明确要求）。
- 每处修改都应能说清「为什么改」。改动较大时先向用户说明思路。

## 去水清单（按优先级删）
1. **无信息量修饰**：「非常」「十分」「有点」「似乎」「仿佛」（无实义时）、「不禁」「忍不住」。
2. **冗余结构**：「进行了调查」→「调查」；「做出回答」→「回答」；「对其进行」→「对其」。
3. **重复表达**：同一信息在相邻句里说两遍；「他点了点头，表示同意」→ 二选一。
4. **空洞心理**：「他心想，这件事一定要办好」——若无具体内容，删除或改为具体念头。
5. **过度对话标签**：连续「他严肃地说」「她愤怒地说」→ 用动作或对话内容本身体现情绪。
6. **废段**：只有「然而」「于是」「接着」却没有推进的过渡句。

## 病句与规范检查
| 类型 | 示例 | 修正 |
| --- | --- | --- |
| 的地得 | 跑的很快 | 跑得很快 |
| 主谓搭配 | 他的心情很激动地跳动 | 他的心激动地跳动 |
| 成分残缺 | 通过这次经历，使我成长 | 这次经历使我成长 |
| 语序 | 我把饭没吃完 | 我没把饭吃完 |
| 标点 | 半角逗号/句号 | 中文全角，…… |
| 数字 | 3个人（叙述中） | 三个人 |

## 节奏收紧
- 长句拆短：一句话超过 40 字且有多个逗号，考虑拆分。
- 段落瘦身：超过 6 句的段落，按语义切分。
- 动作场面：多用短句与强动词，删去修饰。
- 删除削弱语气的词：「大概」「也许」「可能」（叙述确定事件时）。

## 称谓与语气统一
1. 先 `grep` 或 `read_file` 确认每个人物的固定称谓（名字 / 绰号 / 敬称）。
2. 同一叙述视角内，对同一人物的称谓应一致（除非视角人物关系变化）。
3. 人物口癖、方言、文言程度按附录 B 设定统一。
4. 术语（功法名、地名、组织名）以附录 A 为准，发现变体统一为主用名。

## 自检
- 润色后 `read_file` 回读，确认没有误删剧情信息。
- 对比字数：润色通常**减少**字数；若增加，检查是否混入了新内容。
- 通读一遍确认语气连贯，没有因删改产生断裂。
